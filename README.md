# 顺便学英语 · English Along the Way

**中文名：顺便学英语**  
**英文名：English Along the Way**

“Along the Way”既有“在路上”的自然感，也表达“不额外打断手头事情、顺手学一点”的产品理念。

一个轻量、免安装的 Windows 英语学习输入辅助工具。

平时继续使用你熟悉的微软拼音或其他中文输入法；需要时按下全局快捷键，在小浮窗里输入中文，软件会同时显示**完整句子英文翻译**和**词语 / 短语英文释义**。输入完成后，可以一键把中文送回原来的聊天框、文档、浏览器或代码编辑器。

## 效果

例如输入：

> 我今天下午要去学校学习

软件会同时给出两类结果：

- **整句翻译**：I am going to school to study this afternoon.
- **词语 / 短语释义**：我 → I / me，今天 → today，下午 → afternoon，去 → go，学校 → school，学习 → study / learn

目标不是打断正常输入，而是在日常打字的几秒钟里顺便多看一眼英语，让词汇和表达在使用中自然积累。

## 特点

- **无需安装**：解压后双击 `Start.bat` 即可使用。
- **无需管理员权限**：不注册系统输入法，不修改系统级配置。
- **小体积**：程序源码只有几十 KB；首次运行会自动缓存约 6 MB 的本地词语释义数据。
- **无广告**：没有广告、弹窗推广或付费功能。
- **轻松使用**：继续使用原来的中文输入法，不需要重新学习输入习惯。
- **整句 + 词语同时学习**：整句翻译帮助理解自然表达，本地词语释义帮助积累词汇。
- **词语释义本地查询**：下载完成后，词语 / 短语释义不依赖网络即可查询。
- **便携**：整个文件夹可以直接复制到其他 Windows 电脑使用。
- **窗口可调**：浮窗可以自由拖动位置、调整大小，翻译内容区域会随窗口一起伸缩。

## 使用方法

1. 下载或克隆本仓库。
2. 双击 `Start.bat`。
3. 第一次运行时等待本地词语释义数据下载完成。
4. 在任何软件中按 `Ctrl + Alt + Space` 呼出浮窗。
5. 使用原来的中文输入法输入内容。
6. 查看上方的整句翻译和下方的词语 / 短语释义。
7. 按 `Ctrl + Enter` 将中文送回原窗口，按 `Esc` 取消。快捷键对整个浮窗生效，不要求输入框保持焦点。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + Space` | 呼出浮窗 |
| `Ctrl + Enter` | 把中文发送回原窗口 |
| `Esc` | 关闭浮窗并返回原窗口；窗口内任意位置均可使用 |

如果 `Ctrl + Alt + Space` 已被其他软件占用，仍可以双击系统托盘图标打开。

## 系统要求

- Windows 10 / Windows 11
- Windows PowerShell 5.1
- 任意已安装的中文输入法；推荐微软拼音
- 首次下载词语释义数据需要联网
- 整句翻译需要联网

## 翻译与隐私

词语 / 短语释义在本地词典中查询，不会因为每次查词而上传文本。

完整句子的英文翻译目前使用 Google Translate 的公开网络接口，因此用于整句翻译的中文文本会发送到 Google。不要在整句翻译区域输入密码、密钥或其他敏感信息。即使网络翻译不可用，本地词语释义仍然可以继续使用。

## 开发说明

项目使用 Windows PowerShell 启动，并在运行时编译一个小型 C# WinForms 界面。这样可以直接利用 Windows 自带运行环境，无需额外安装 Python、Node.js、.NET SDK 或其他运行时。

当前主要逻辑包括：

- Win32 全局热键注册
- 窗口级 `Esc` / `Ctrl+Enter` 快捷键处理
- WinForms 便携浮窗（支持拖动与缩放）
- 本地中英词语释义查询与简单分词
- 约 0.7 秒防抖的整句在线翻译
- 通过剪贴板将输入内容送回原窗口
- 系统托盘驻留与退出
